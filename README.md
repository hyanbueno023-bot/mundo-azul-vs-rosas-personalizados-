Mundo Azul vs Rosas Personalizados

Arquivos: index.html, style.css, script.js.

O site permite adicionar nome, preço, detalhes e foto dos produtos pelo botão “Adicionar produto”.

IMPORTANTE: troque https://wa.me/5500000000000 pelo WhatsApp real da loja em index.html e script.js.

Os produtos ficam salvos no navegador nesta versão. Para compartilhar o catálogo com todos os clientes, será necessário um banco de dados/armazenamento online.

No GitHub: envie os 3 arquivos para a raiz do repositório e publique pelo Settings > Pages > Deploy from a branch > main (ou principal) > /(root) > Save.
